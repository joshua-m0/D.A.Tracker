What to do with these keys:

1. Copy the Public Key and paste it into index.html:
var VAPID_PUBLIC_KEY = 'PASTE_PUBLIC_KEY_HERE';

2. Store the Private Key safely on your backend server (e.g. Render, Railway, Firebase Functions).

3. Your server uses both keys when calling the Web Push API to send notifications.

Note: Without a backend server, your app will still show in-app alarm toasts (already working) — the Web Push keys are only needed for notifications when the app is closed.
